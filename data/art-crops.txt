# Art crop boxes, used to cut card art out of full card pictures for small thumbnails
# (stack list, graveyard/exile piles). Planesnomad data, not Forge's.
#
# Coordinates are pixels of a Scryfall "normal" picture (488 x 680); other sizes scale.
#
#   SET[,SET...] = left,top,right,bottom      one box per set or group of identically
#                                             formatted sets (Forge set codes and/or Forge's
#                                             short picture-folder codes, e.g. 2ED and U)
#   SET@layout[,...] = left,top,right,bottom  a box for one card layout in those sets
#   *@layout = left,top,right,bottom          a layout box for every set that has a normal box
#   ALT-ARTS-NO-CROP = SET[,SET...]           in these sets, alternate printings (art index 2+)
#                                             of non-basic-land cards get no crop: they may be
#                                             showcase/borderless frames with the art elsewhere
#
# Lines can continue with a trailing backslash. Boxes sit slightly inside the art window,
# because frames vary a few pixels card to card. Only list sets checked against real pictures.
#
# Special layouts (planeswalker, saga, split, flip, battle, class, case) get NO crop unless a
# layout box is listed: their art window is elsewhere. Adventure, double-faced fronts and
# normal cards use the set's normal box. Not handled yet (no crop): split, flip, battle,
# class, case.
#
# Checked 2026-11-21: per-set sheets of 6 cards for 2ED, TOR, SHM, FUT, KTK; then one random
# normal card from every set below (a forge picture cache culled to Core, Expansion, Commander,
# MH1-3, LTR, CMR, CLB). Future Sight "futureshifted" frames: not handled yet.
